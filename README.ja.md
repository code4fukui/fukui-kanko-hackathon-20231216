# fukui-kanko-hackathon-20231216

このリポジトリには、2023年12月16日に開催されたハッカソン「**シビックテックで次世代観光を創出せよ**」の資料が含まれています。本イベントは、オープンデータを活用して福井県の革新的な観光アプリケーションを開発することに焦点を当てました。

![2022 Fukui Tourism Hackathon](https://img.sabae.cc/data/20230108/5a5d231e-c64c-4d74-b489-146e29765734.jpg)

*昨年度の様子。[詳細はこちら](https://fukuno.jig.jp/3818)*

## イベントについて

本ハッカソンの目的は、デジタル人財の発掘・育成と、福井県の観光を活性化する新たなDX（デジタルトランスフォーメーション）施策の創出です。参加者はチームを組み、福井県の観光に関するオープンデータを活用して新しいアプリケーションを開発しました。

**主催:**
* 福井観光DX推進マーケティングデータコンソーシアム
* [一般社団法人コード・フォー・ジャパン](https://www.code4japan.org/)

## 開催概要

* **日時:** 2023年12月16日(土) 13:00 - 18:00 (JST)
* **会場:** [jig.jp開発センター](https://maps.app.goo.gl/auSTxAXxVbEm8Gdt5)（福井県鯖江市）
* **対象:** 中学生、高校生、高専生、大学生、一般
* **持ち物:** ノートパソコン（参加者各自持参）
