# fukui-kanko-hackathon-20231216

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

This repository contains materials for the hackathon **"Create Next-Generation Tourism with Civic Tech,"** held on December 16, 2023. The event focused on developing innovative tourism applications for Fukui Prefecture using open data.


![2022 Fukui Tourism Hackathon](https://img.sabae.cc/data/20230108/5a5d231e-c64c-4d74-b489-146e29765734.jpg)

*A look at the previous year's event. [Read more here](https://fukuno.jig.jp/3818).*

## About the Event

The goal of this hackathon was to discover and nurture digital talent and to generate new DX (Digital Transformation) initiatives to revitalize tourism in Fukui. Participants formed teams to build new applications using open data related to Fukui tourism.

**Organized by:**
*   Fukui Tourism DX Promotion Marketing Data Consortium
*   [Code for JAPAN](https://www.code4japan.org/)

## Event Details

*   **Date:** December 16, 2023 (Saturday), 13:00 - 18:00 JST
*   **Venue:** [jig.jp Development Center](https://maps.app.goo.gl/auSTxAXxVbEm8Gdt5), Sabae City, Fukui
*   **Target Audience:** Middle school students, high school students, college students, and the general public.
*   **Requirements:** Participants were required to bring their own laptops.
